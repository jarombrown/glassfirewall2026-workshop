# Browser-only fallback

You can still take part if MCP setup or AI access fails.

1. Pair with someone whose setup passed the readiness check.
2. If no working partner is available, use `docs/fallback/normal-traffic.json` in any AI chat account you already have. It contains a small capture from normal lab browsing, not a full browser HAR. Review its synthetic content before uploading.
3. Compare the response fields with `docs/fallback/speaker-page.txt`, which describes what the speaker cards display.
4. Ask AI to identify observations and possible privacy boundaries. Challenge one of its assumptions.
5. Complete FINDING-WORKSHEET.md.

This fallback contains only the normal browsing evidence. It does not provide hidden-route answers and is not part of the browser discovery exercise.
