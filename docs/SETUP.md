# Local participant setup

The local workflow uses a different Chrome DevTools MCP configuration from Codespaces. It is preserved on the repository's [`local-setup` branch](https://github.com/jarombrown/glassfirewall2026-workshop/tree/local-setup).

Follow the [local participant instructions](https://github.com/jarombrown/glassfirewall2026-workshop/blob/local-setup/docs/SETUP.md) from that branch. Do not mix the local and Codespaces configurations in one checkout.
